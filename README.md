# Uhandisi Tutors

Where Learning Meets Excellence.

Uhandisi Tutors is a tutoring service offering expert support in Maths, Science, and Engineering for high school and university students across South Africa. Students can browse available subjects, learn how the tutoring process works, read testimonials, and book a session directly through the website.

## Tech stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Local development

```sh
npm i
npm run dev
```

## Build

```sh
npm run build
```
